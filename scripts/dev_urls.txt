# Development set for the umbrella-tag step (docs/tagging-algorithm.md),
# gathered on 2026-11-15 from web searches, Stack Overflow, GitHub,
# Wikipedia and documentation contents. Steps are tuned on this set; the
# realistic set (realistic_urls.txt) stays a test set. None of its topics is
# in the other three sets.
#
# Four big interests whose pages split into subtopics (iceland, sailing,
# godot, wedding-planning) should each get an umbrella tag. Two groups of
# separate topics that only share a field (infrastructure-tools,
# water-sports) should not. Three medium topics and 13 single pages complete
# it; three single pages share a word with a tool (Prometheus, terraforming,
# Waiting for Godot).
#
# "# cluster: name" starts a topic. "one-" topics have 1 page.
# "# group: name: topic ..." names related topics, for a coarser second
# score. "# ambiguous: a b ..." names topics that use one word in different
# meanings. "# thin: URL" marks a page that loads with under 500 characters
# of text.
